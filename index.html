FLAGSHIP

Intelligent Face Tracker

Real-time unique visitor counting
  • Real-time visitor tracker combining 2 models: YOLO face detection and ByteTrack for stable track IDs across frames.
  • InsightFace (ArcFace) embeddings with cosine similarity recognise returning visitors, so each person is counted once.
  • New visitors are registered only after consistent observations, with multiple embeddings stored per visitor for accuracy.
  • Visitors stored in SQLite; 2 event types (ENTRY/EXIT) logged with timestamped face images from 3 inputs: camera, video and stream.
